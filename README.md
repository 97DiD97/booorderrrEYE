# FloatingEyeBorder
Дополнение к FloatingEye (кладётся в plugins/ рядом с ним).

/eye border <блоков> [секунд]  - глаз летит к ближайшей границе, рисует руны и расширяет барьер
/eye border stop               - остановить
/eye border limit [число]      - посмотреть/сменить лимит блоков (0 = без лимита)
/eye border reload             - перечитать config.yml

Сборка: залей папку в GitHub-репозиторий -> вкладка Actions -> build -> Artifacts -> FloatingEyeBorder.
